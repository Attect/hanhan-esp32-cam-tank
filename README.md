# ESP32 遥控坦克

基于 ESP32-COM / ESP32-CAM 的 WiFi 遥控坦克固件，支持实时视频流、网页/手柄/键盘多方式操控。

## 功能特性

- **实时视频流**：OV3660 摄像头 MJPEG 推流，支持独立开关
- **智能画质**：支持手动切换分辨率，自动画质模式下履带运动时自动降为 240P 保证流畅度，静止 1.5s 后恢复
- **多操控方式**：
  - 手机浏览器：多点触控虚拟摇杆 + 滑杆 + 按钮
  - 电脑浏览器：键盘 WSAD + 方向键 + 空格
  - Xbox 手柄：左摇杆移动、右摇杆 Y 轴控制铲子、A 键切换灯光
- **铲子模块**：PWM 舵机控制，支持磁吸更换为照明模块（共用 GPIO2）
- **单侧履带控制**：页面左右两侧独立前进/后退按钮，方便微调姿态
- **LED 车灯**：亮度 0~255 可调，低亮度无闪烁
- **自动休眠**：无客户端 5s 后自动关闭摄像头、关灯、降低 WiFi 功率；有新连接时自动唤醒
- **WiFi 状态指示**：连接前 LED 低亮度闪烁，连接成功后熄灭

## 接线表

### 电机驱动（L298N）

| 功能 | GPIO | 说明 |
|------|------|------|
| 左电机 IN1（方向） | 12 | Digital |
| 左电机 IN2（PWM） | 13 | LEDC 通道 3 |
| 右电机 IN3（方向） | 15 | Digital |
| 右电机 IN4（PWM） | 14 | LEDC 通道 2 |

> ENA/ENB 跳线帽短接（固定 HIGH），单 PWM 调速。

## 编译烧录

### Arduino IDE

1. 在 **文件 → 首选项** 中添加 ESP32 板包地址。
2. 选择开发板 `ESP32 Dev Module` 或对应 ESP32-CAM 板型。
3. 安装依赖库 **WebSockets**。
4. 打开 `tank.ino`，修改顶部的 WiFi SSID 和密码。
5. 选择正确端口，点击上传。

### PlatformIO

```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
lib_deps = links2004/WebSockets @ ^2.4.1
```

## WiFi 配置

在 `tank.ino` 顶部修改：

```cpp
const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
```

烧录后打开串口监视器（波特率 `115200`），查看 ESP32 获取的 IP 地址。在同一局域网内的浏览器访问该 IP 即可操控。

## 操控说明

### 网页操控

- **中间**：实时摄像头画面
- **左侧摇杆**：控制坦克移动（前/后/左/右），支持 PWM 调速，轻推慢走
- **左侧上下按钮**：单独控制左履带前进/后退
- **右侧垂直滑杆**：控制铲子抬升/下降（上抬下放）
- **右侧上下按钮**：单独控制右履带前进/后退
- **💡 按钮**：切换 LED 车灯
- **顶部画质按钮**：自动 / 240P / 480P / 高清
- **📷 按钮**：独立开关摄像头传输

### 键盘（电脑端）

| 按键 | 功能 |
|------|------|
| W / S | 前进 / 后退 |
| A / D | 原地左转 / 原地右转 |
| ↑ / ↓ | 铲子抬起 / 放下 |
| 空格 | 切换灯光 |

### Xbox 手柄

| 操作 | 功能 |
|------|------|
| 左摇杆 | 坦克移动 |
| 右摇杆 Y 轴 | 铲子控制 |
| A 键 | 切换灯光 |

## 网络端口

| 服务 | 端口 | 说明 |
|------|------|------|
| HTTP 网页 | 80 | 操控页面 |
| MJPEG 视频流 | 81 | `/stream` |
| WebSocket | 82 | 低延迟控制指令 |

## WebSocket 协议

客户端 → 服务器：

| 格式 | 示例 | 说明 |
|------|------|------|
| `M,<left>,<right>` | `M,255,-255` | 电机速度 `-255~255` |
| `S,<angle>` | `S,50` | 铲子角度 `0~100` |
| `L` | `L` | 切换灯光开关 |
| `L,<brightness>` | `L,128` | 设置灯亮度 `0~255` |
| `Q,<mode>` | `Q,AUTO` | 画质 `AUTO/QVGA/VGA/SVGA` |
| `C,<1/0>` | `C,0` | 摄像头开关 |

## 安全提示

- HTTP / WebSocket / 视频流均无身份验证，同一局域网内的设备均可访问。
- 首次测试建议将坦克架离地面，确认电机转向正确后再放下行驶。
